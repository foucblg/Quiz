# Quiz on inclusiveness

A quiz on digital inclusiveness. Questions (single or multiple choice) are grouped into categories,
and each category appears at a configurable rate. Everything is driven by a JSON file.

Part of [PAi13](https://github.com/foucblg/PAi13), a serious game on inclusive digital services built
with the Lyon metropolitan area. Live demo: [foucblg.github.io/Quiz](https://foucblg.github.io/Quiz/).

Technical documentation: [documentation.md](documentation.md).

## Run locally

```bash
npm install
npx ng serve   # http://localhost:4200/
```

Stack: Angular 18, TypeScript.
